# Amazon Clone

A responsive Amazon homepage clone built using HTML and CSS. This project recreates the basic layout and design of the Amazon landing page for learning and practice purposes.

## 🚀 Features

- Responsive navigation bar
- Search bar
- Hero section
- Product categories
- Footer section
- Clean and user-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3
